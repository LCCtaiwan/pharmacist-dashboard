# 法規查核與公開來源

查核日期：2026-08-03（Asia/Taipei）

## 現行規則摘要

依《醫事人員執業登記及繼續教育辦法》（修正日期：民國 111 年 8 月 26 日）：

- 藥師屬該辦法所稱醫事人員。
- 繼續教育法定分類為：專業課程、專業品質、專業倫理、專業相關法規。
- 藥師每六年總積分應達 120 點；專業品質、專業倫理與專業相關法規合計至少 12 點，其中應包括感染管制與性別議題，超過 24 點者以 24 點計。
- 課程及積分須由中央主管機關認可的醫事人員團體審查認定及採認。

本儀表板不追蹤個人積分或換照期限。上述規則只用來界定為何優先監看專業品質、倫理、法規、感染管制及性別議題；「稀有學分」不是法規用語。

主要法規來源：

- 全國法規資料庫：https://law.moj.gov.tw/LawClass/LawAll.aspx?PCode=L0020181
- 衛福部醫事系統入口公告（藥師積分查詢改至繼續教育積分系統）：https://ma.mohw.gov.tw/portal/
- 衛福部繼續教育積分系統：https://cec.mohw.gov.tw/

## 來源判讀原則

GAS 的 `?format=rss` 目前只輸出 `Courses` 工作表已收集的課程，不能繞過台灣藥學會的 HTTP 403，也不等同於學會官方 RSS。

1. 主辦單位公告可確認日期、費用與報名資格，不一定能確認最終積分採認。
2. 審查列表中的「通過」可作為重要證據，但仍應確認職類、課程類別與實際完成條件。
3. 課名含「倫理」「法規」「感染」「性別」等關鍵字，自動標示為稀有學分。
4. 原公告未提供名額、費用或截止日時保留空白，不填推測值。
5. 開課內容、名額與採認狀態可能變動，報名前應點回來源再次確認。
