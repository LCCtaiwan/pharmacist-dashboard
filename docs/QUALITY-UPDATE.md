# 課程資料品質更新（2026-11-04）

## 範圍與部署狀態

此更新沿用既有 Actions → JSON/RSS → Pages，以及 Actions → GAS → Google Sheet。修改在隔離工作目錄測試；本文件不代表已推送或部署。既有 `web/data/` 未覆寫，正式 Sheet 未異動。

## 新版來源能力

- 臺灣臨床藥學會 B1：公開 HTML 表格直接解析「藥師執照繼續教育」。不混入 B2 藥學師資積分。由表單的公開 POST 搜尋換頁，必須核對回應頁碼與新課程 ID。
- B1 預設最多4頁、每次最多15筆詳情，HTTP請求至少間隔350毫秒。這是有上限的最新列表採集，不是11,000餘筆歷史全量。超出上限標示 `partial` 與實際取得數；不宣稱全台完整涵蓋。若要調大上限，先評估網站負載與使用條款。
- B1 詳情必須與清單課程的 hidden ID、名稱一致。任何不符都拒絕套用，保留清單資料並標示異常，不能把另一門課的積分或報名狀態接過來。
- B1 清單總積分、詳情各節積分與類型分開保存；詳情認證字號有「臨藥繼字第」才標示已核定。明示「不開放報名」會保留，不以已有認證推斷可報名。
- 台灣藥學會：解析活動列表與審查狀態、民國日期、起迄時間。多頁但尚未遍歷時明確標示首頁，不推斷報名或積分數。
- 桃園RSS：發佈時間與上課日分離，詳情限定 `.entry-content`，不拿RSS pubDate作上課日。
- 南瀛、大臺中、其他公開HTML：限定公告連結與內容容器。容器無法確認時保留「待確認」，不再抓整頁任意連結附近500字。公開詳情不支援的網站需後續追加經驗證的 adapter。
- 403、登入、CAPTCHA 不會繞過。失敗保留原資料並顯示來源錯誤；前端正常載入不等於所有來源正常。

## 品質規則

1. 議題關鍵字不等於正式積分類別；未知點數、分類、核定和報名各自保持未知。
2. 日期驗證民國／西元、合法年月日、時分與合理年份。不從旁邊公告或報名截止推算上課起迄。
3. 點數不從時數推估。重複類別文字和別名不重複加總，不借用同頁其他職類的積分。同類點數矛盾時留待確認。
4. 詳情失敗不覆寫前次有證據的欄位；來源整批失敗／筆數驟降保留前次資料。保留值標示待確認，不改寫成新鮮已驗證內容。
5. 保留穩定課程ID和首次發現時間；額外保存 `publishedAt`、`datePrecision`、`evidence`、`dataQuality`、`creditCategories`、`registrationUrl`、`sessions`。
6. 多節課活動總積分不代表只參加其中一節即可取得全部積分；節次保存在 `sessions`，詳情與報名資格以原公告為準。

## GAS與歷史資料

新欄位追加到 `Courses_All`／月份表，物件以JSON序列化；API還原欄位。月份按臺北時間，不按UTC前一天分月。過去年份異常分頁不自動刪除。月份分頁保留為歷史快照，並非現行課程唯一清單；**現況以 `Courses_All` 與來源狀態為準**。歷史快照可能包含已更正、已移動日期或舊版錯誤，清理需另行確認範圍。

GAS畫面與API使用 `RunHistory` 最近同步的生成時間，不再每次開網頁就當成剛更新。新增欄位生效需更新GAS程式與部署版本，只有部署Pages不會改GAS。保留現有Token設定，不建立新權限或憑證。

## 驗證與發布

```
npm ci --ignore-scripts --no-audit --no-fund
node scripts/sync-gas-dashboard.mjs
npm test
git diff --check
```

離線測試含真實公開HTML的最小fixture、錯列日期、職類積分、重複類別、日期精度、TSHP分頁與身分不符。UI採VM/DOM測試；瀏覽器啟動受環境限制，未完成真實手機視覺驗收。

本機採集可使用 `node scripts/collect-public-courses.mjs --output-dir outputs/preview-data`；不會同步Sheet或部署。未給output-dir會更新repo的 `web/data/`。

發布應先檢查新資料與來源錯誤，再推送已授權分支／提交。Actions安裝鎖定依賴、跑完整測試、採集、同步Sheet、提交資料。Pages只跟隨成功採集工作流部署，另保留手動部署。發布後檢查正確commit、Actions結果、正式JSON時間、GAS欄位與來源健康狀態。
